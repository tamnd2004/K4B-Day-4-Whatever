# Evaluation Metadata Skills Taxonomy

In `starter_v0/data/eval_base.json`, `skill` is a semantic competency tag inside each case's `metadata` object (e.g. `route_device`, `clarify_asset`, `multiturn_correction`, `confirm_write`). It categorizes test cases into diagnostic capability groups, allowing teams to analyze failure patterns across specific agent behaviors and structure their 10 custom team evaluation cases in `data/eval_group.json`.
