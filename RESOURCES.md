# IT Helpdesk Tool Calling & Prompt Engineering Resources

## Knowledge

- [OpenAI Function Calling & Structured Outputs Guide](https://platform.openai.com/docs/guides/function-calling)
  Authoritative specification of tool definitions, JSON schemas, and function calling mechanisms in modern LLMs. Use for: understanding how `tools.yaml` maps to OpenAI/OpenRouter tool schemas.
- [OpenRouter Tool Calling Documentation](https://openrouter.ai/docs/tools)
  Documentation on how OpenRouter standardizes tool-calling across different model providers. Use for: troubleshooting provider responses and parameter serialization.
- [Anthropic Tool Use Comprehensive Guide](https://docs.anthropic.com/en/docs/build-with-claude/tool-use)
  Best practices for tool descriptions, parameter explanations, and preventing hallucinated tool inputs. Use for: crafting disambiguated tool descriptions.
- [Prompt Engineering Guide (DAIR.AI)](https://www.promptingguide.ai/)
  Reference guide for system prompt structure, role-based prompting, few-shot examples, and guardrails. Use for: structuring `system_prompt.md`.

## Wisdom (Communities)

- VinUni AIA Course Forum & Discord / Class Channel
  Direct access to Keycoach, TAs, and peer teams working on Day 04. Use for: clarifying assignment rubrics, rate limit questions, and submission checkpoints.
- [OpenAI Developer Community - Function Calling](https://community.openai.com/c/api/11)
  Active community discussing edge cases in tool calling, multi-turn tool loops, and schema validation. Use for: troubleshooting complex tool routing behaviors.
